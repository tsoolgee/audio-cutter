# ✂️ חותך שמע

כלי קטן לחיתוך קבצי MP3 (וגם WAV ופורמטים אחרים). זה קובץ HTML אחד: מורידים, לוחצים פעמיים, והוא נפתח בדפדפן.
אין התקנה, אין אינטרנט, והקובץ לא יוצא מהמחשב.

**הורדה:** [audio-cutter.html](https://github.com/tsoolgee/audio-cutter/releases/latest/download/audio-cutter.html)
· **גרסה מקוונת:** https://tsoolgee.uk/MEDYA-CATER

## מה אפשר לעשות
- **שמירת קטעים רצויים**: מסמנים כמה קטעים שרוצים לשמור, ושומרים אותם מחוברים לקובץ אחד או כל קטע לקובץ נפרד.
- **הסרת קטעים לא רצויים**: מסמנים כמה קטעים להסרה, וכל השאר נשמר לקובץ אחד.
- **שילוב של שניהם:** לכל קטע בטבלה אפשר לבחור "לשמור" או "להסיר". למשל, לשמור קטע ולהסיר את תחילתו באותה פעולה.
- לכל קטע יש שני סמנים בצבע משלו, ואפשר לגרור אותם על הגל. קטעים לשמירה מסומנים בצבעים קרים, וקטעים להסרה בצבעים חמים ובפסים.
- לכל סמן יש תיבת זמן, והיא מתעדכנת בזמן הגרירה. אפשר גם להקליד בה זמן מדויק: `2:30`, `1:02:30`, `150`, `2:39.5`.
  החצים ↑/↓ בתוך התיבה מזיזים את הזמן בשנייה, ועם Shift בעשירית שנייה.
- "קפוץ לזמן" מעביר ישר לכל נקודה בקובץ, בלי לגלול. יש גם זום עם Ctrl+גלגלת.
- "דלג בניגון על מה שלא יישמר" מאפשר לשמוע את התוצאה לפני השמירה.

## איכות
קבצי MP3 ו-WAV נחתכים **בלי קידוד מחדש**, כך שאין שום פגיעה באיכות. גם קובץ של 5 שעות נחתך מיד.
ב-MP3 הדיוק הוא ברמת פריים (בערך 1/40 שנייה). פורמטים אחרים (M4A, OGG, FLAC) נשמרים כ-WAV.

## קיצורי מקשים
| מקש | פעולה |
|---|---|
| רווח | נגן / עצור |
| ← / → | 5 שניות אחורה / קדימה (עם Shift: שנייה אחת) |
| I / O | קובעים את ההתחלה / הסיום של הקטע המסומן לפי המיקום הנוכחי |
